# 26.5.0 Office Engine Feasibility Research

Status: research only. This branch is based on the accepted 26.4.3 release and must not change the stable release branch.

## Product constraints

- Target device: HERAN HD-50UDF26
- Android 5.0.1 / API 21
- ARM64 (AArch64), 2 GB RAM
- One offline APK, maximum target size 1 GB
- TV remote / D-pad operation
- Keep the existing OldTV Revival launcher and file manager
- Prioritize broad DOCX, XLSX and PPTX editing capability

## Candidate A: current Collabora Office mobile source

### Verified source configuration

- Inspected the public read-only source mirror: https://github.com/CollaboraOnline/online.mirror
- Current `main` branch `android/app/build.gradle` explicitly sets `minSdk 26`, `targetSdk 37`, compile SDK 37 and NDK 29.0.14206865.
- The older `distro/collabora/co-25.04` branch also explicitly sets `minSdk 26` (compile SDK 36, target SDK 35, NDK 28.2.13676358).
- Therefore, current Collabora Android app source does not directly target this TV's API 21. Lowering minSdk alone would not prove compatibility: AndroidX dependencies, Java APIs, native library API level and runtime behavior still need audit.
- The public source mirror is read-only; upstream development is hosted on Collabora Gerrit.

### Build and integration

1. Collabora's Android build guide says native parts are built on Linux or macOS, the engine is built before the Android app from the same monorepo, and the engine requires Android NDK 27 or later.
2. The guide lists arm64-v8a as supported and describes the CPAndroidAarch64 engine build.
3. The official guide documents building the Collabora Android app from its monorepo. It does not document embedding the full editor as a library in an unrelated APK.
4. The Android app currently depends on AndroidX UI libraries and a project-local `:lib` module, so integration is more than adding a single AAR dependency.

- https://github.com/CollaboraOnline/online.mirror/blob/main/android/app/build.gradle

## Candidate B: current LibreOffice Viewer

- F-Droid lists LibreOffice Viewer 26.2.6.3 for arm64-v8a, requiring Android 5.0 or newer, with an APK size of about 83 MiB.
- It supports ODF and Microsoft Office formats including DOCX, XLSX and PPTX.
- Important limitation: F-Droid describes it as a viewer; editing is experimental and explicitly not considered production-ready. It is therefore a useful API-21/ARM64 compatibility reference and possible rendering-engine research candidate, but not yet a suitable complete editing replacement.
- Its current Android 5+ package listing does not by itself prove that the app can be embedded into OldTV Revival or that it has good D-pad support.

Sources:
- https://f-droid.org/packages/org.documentfoundation.libreoffice/
- https://f-droid.org/en/packages/org.documentfoundation.libreoffice/

## Candidate C: historical Collabora Office

- Historical Collabora Office 6.4.14 (2021) was listed for Android 5.0+ / API 21 and arm64-v8a.
- Historical Collabora Office 4.2.11 was also listed for Android 5.0+ / API 21 and was a roughly 277 MiB universal package.
- Collabora's own 2019 Android beta article stated Android 5.0 as the minimum and described document editing, including text and table editing.
- This shows that a LibreOffice-based Android editor previously targeted API 21. However, these historical app versions are not recommended as the final engine: their old core, security/format support, toolchain and compatibility with current Android libraries need a separate audit. They are research evidence only, not a release recommendation.

## Cross-cutting assessment

- OS/ABI: current Collabora source is blocked by minSdk 26; current LibreOffice Viewer is listed as Android 5+ and arm64. This makes Viewer a more promising API-21 compatibility reference, but its editing limitations are significant.
- Offline: Collabora documentation describes local document editing; the LibreOffice Viewer is a local document app. Real offline testing is still required.
- TV UX: none of the sources proves a good TV remote/D-pad experience. Focus navigation and landscape behavior must be tested.
- Memory: 2 GB RAM is a major risk. Test cold start and representative documents on the real TV.
- APK size: F-Droid's arm64 Viewer package is listed at about 83 MiB; historical Collabora universal packages were much larger. The final merged APK must be measured.
- License: LibreOffice Viewer is listed under MPL 2.0. Collabora is MPL 2.0 plus other component licenses. Preserve notices and audit every bundled component before redistribution.

## Updated proof-of-concept plan

1. Keep 26.4.3 stable and isolate all experiments on `research/26.5.0-office-engine`.
2. Use current LibreOffice Viewer as the first API-21/ARM64 compatibility reference; inspect its exact source revision, Gradle configuration, native library build flags and license notices.
3. In parallel, inspect historical Collabora API-21 source only to understand which editor shell and native interfaces previously worked on API 21. Do not bundle an old APK or copy binary components into the product.
4. Determine whether a supported, current LibreOffice core can be built for API 21 with the modern toolchain. Check native minimum API settings and all dependencies before attempting an app build.
5. Prototype the editor as a separately launchable activity/module while preserving OldTV Revival's existing launcher and file manager. Only after API-21 proof should single-APK integration be attempted.
6. Verify local offline open/edit/save/reopen for DOCX, XLSX and PPTX; Chinese text/fonts; images/tables; formulas; slide layouts; D-pad focus; Back behavior; RAM; startup time; and final APK size.
7. Complete license/notice review before bundling or redistribution.

## Decision

Do not lower the current Collabora minSdk by changing one number, do not merge an unverified engine, and do not replace 26.4.3. Current Collabora source is not API-21 compatible as configured. LibreOffice Viewer is API-21/ARM64 listed but its editing remains experimental. Continue source-level feasibility work and a controlled proof of concept before choosing the production engine.
